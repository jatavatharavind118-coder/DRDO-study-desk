# DRDO Study Desk

Study resources for GATE ECE, ISRO and DRDO, with topic lessons, quizzes, diagrams, exam papers and browser-based progress tracking.

Live site: https://gate-ece-study-desk.skillfulyak1.chatgpt.site/

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. Progress is stored in your browser.
